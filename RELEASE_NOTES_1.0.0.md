# Irrigation Card 1.0.0

Erste Veröffentlichung: Bewässerungssteuerung für Hunter Hydrawise im Glas-Look der NAS Card.

## Highlights

- Zonen über den Geräte-Picker hinzufügen – Entitäten werden automatisch zugeordnet
- Start mit 5 / 10 / 15 / 30 min, Stopp, Automatik an/aus
- Restzeit mit Fortschrittsbalken, Regensensor, Tageswerte, Pumpe
- Foto als Banner oder Hintergrund

## Installation

Über HACS als benutzerdefiniertes Repository (Typ **Dashboard**) hinzufügen und anschließend den Browser vollständig neu laden.
